# ponpon-player

ぽんぽんの配信画面・演出・操作パネルをまとめた、HTMLとJavaScriptのリポジトリです。

## 画面とファイル

| ファイル | 役割 |
| --- | --- |
| [index.html](index.html) | 「魂モード」の表示画面 |
| [studio.html](studio.html) | カメラ／ウィンドウ映像に、追従ネームプレート・字幕・HP・ギフト演出を重ねる画面 |
| [control.html](control.html) | 字幕・口上・ギフト・HPなどを操作するパネル |
| [model.onnx](model.onnx) | studio.htmlがタッチ操作のある端末向けに選ぶ、320入力の検出モデル |
| [model480.onnx](model480.onnx) | studio.htmlがタッチ操作のない端末向けに選ぶ、480入力の検出モデル |
| [ort/](ort/) | ブラウザでモデルを動かすONNX RuntimeのJavaScript・WebAssemblyファイル |

画面はモデルや `ort/` を相対パスで読み込みます。ファイルの移動や改名を行う場合は、読み込み元も合わせて確認してください。

## ローカルで開く

Python 3が利用できる環境で、このリポジトリのフォルダから起動します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

- 魂モード：<http://127.0.0.1:8000/index.html>
- スタジオ：<http://127.0.0.1:8000/studio.html>
- 操作パネル：<http://127.0.0.1:8000/control.html>

スタジオと操作パネルは、同じブラウザの同じプロフィールで開き、URLのホスト名とポートをそろえてください。両画面は `BroadcastChannel('ponpon')` で操作情報を共有します。

スタジオでは「カメラ開始」で映像入力を選べます。「ウィンドウから取り込む」では、Camo Studio等の画面を選択して取り込む処理があります。カメラ・画面共有の許可はブラウザ側で行います。

## 保存先と連携

| 情報・機能 | 保存先／連携先 |
| --- | --- |
| HTML、演出処理、検出モデル、実行用ファイル | このGitリポジトリ |
| カメラ選択、回転、切り抜き、プレート表示設定、最高レベル | 使用中ブラウザのlocalStorage |
| スタジオの現在のレベル・EXP | 配信セッション内。再読込時はLv.1・EXP 0から開始 |
| 操作パネルからスタジオへの操作 | 同じオリジンのBroadcastChannel |
| 外部イベントとの連動 | WebSocketのポート8765に接続する別プログラム |

ブラウザに保存される設定や記録は、Gitへの保存対象には含まれません。

## 外部コネクタの確認事項

`studio.html` はローカルの `connector.js` との連動を想定し、`ws://localhost:8765` に接続します。`index.html` にも同じ接続先があり、`control.html` にもWebSocket送信処理があります。

このリポジトリには `connector.js` や、その起動手順は含まれていません。外部イベントの自動反映を再現するには、既存コネクタの保管場所・起動方法・設定を確認する必要があります。
